# ✨ Cosmora

Cosmora is an intelligent skincare and haircare recommendation platform that helps users understand their skin and hair concerns through image analysis and personalized recommendations. The platform combines deep learning models for skin issue detection with an LLM-powered assistant for customized hair care guidance, providing users with tailored insights to improve their personal care routines.

---

## ✨ Features

* 📸 Skin analysis using facial images
* 🧠 Deep learning-based skin issue detection
* 💇 Personalized hair care recommendations
* 🤖 LLM-powered hair care assistant
* 📊 Detailed analysis reports and recommendations
* 💻 Simple and user-friendly interface
* 📱 Responsive design for seamless access across devices

## 🔍 How It Works

### 🧴 Skin Analysis

* Users upload a facial image.
* A deep learning model analyzes the image to detect skin concerns such as acne, pigmentation, dark spots, wrinkles, and other visible conditions.
* Based on the detected concerns, the platform presents a detailed analysis along with personalized skincare recommendations.

### 💇 Hair Care Analysis

* Users provide details about their hair type and specific concerns.
* An LLM generates personalized hair care recommendations, including suitable routines, maintenance tips, and general care guidance tailored to the user's input.
